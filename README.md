# 账单分析器

> 把微信、支付宝导出的账单，变成一份看得懂的消费报告。

拖进去，点一下，出一份报告。**全程离线运行**，不联网、不注册、不上传——账单一步都不会离开你的电脑。

---

## 这个工具解决什么问题

微信和支付宝都能导出账单，但导出的是几千行 Excel。「这个月餐饮花了多少」「哪几个月花超了」「哪个商户最费钱」——这些结论都得自己一行行算。

这个工具就是干这个的：**读你导出的账单，自动归类、算好、画好图，出一份报告。**

它顺手帮你处理掉几个导账单时一定会遇到的坑：

- **两个渠道都导出过？** 同一笔交易在微信和支付宝各记一次，它会自动识别并去掉重复
- **微信导出的文件前面有十几行说明文字？** 它自己找表头在哪一行，不需要你手动删
- **金额写法不统一？** `¥1,234.00`、`￥88.5`、`(100.00)` 都能正确读出来
- **转账也算进支出了？** 「不计收支」的记录不会被算进消费统计

## 报告里有什么

| 板块 | 内容 |
| --- | --- |
| **总览** | 总支出、总收入、净支出、日均支出、笔数 |
| **支出构成** | 环形图 + 明细表，按分类拆开，一眼看出钱花在哪 |
| **月度趋势** | 逐月支出柱状图，涨跌一目了然 |
| **花钱最多的商户** | TOP 12 排名 |
| **异常消费** | 自动挑出明显偏离你平时习惯的单笔消费 |
| **数据体检** | 读了几行、去了多少重复、有多少笔是转账——清洗过程全部可查 |

报告是一个**单文件 HTML 页面**：双击就能打开，不依赖网络和任何外部资源，存起来、发给别人、当附件都行。

## 下载使用

### 第 1 步：下载

到 **[Releases](https://github.com/Sikitokotori/money-analysis/releases)** 页面下载最新的 zip
（文件名形如 `账单分析器-v0.2.0-win64.zip`，约 32 MB）。

### 第 2 步：解压

解压到任意位置——桌面、D 盘、文档文件夹都可以，**不需要安装**。解压后长这样：

```
账单分析器\
├─ 账单分析器.exe      ← 双击这个
├─ 使用说明.txt
└─ _internal\          ← 程序依赖，别删
```

> ⚠️ **整个文件夹要一起带着走**，不能只把 `账单分析器.exe` 单独拖出来。
> 想放桌面的话：右键 exe →「发送到」→「桌面快捷方式」。

### 第 3 步：导出账单

**微信**
1. 打开微信 →「我」→「服务」→「钱包」
2. 右上角「账单」→ 右上角「常见问题」
3. 「下载账单」→「用于个人对账」
4. 选好时间范围 → 填邮箱 → 提交
5. 邮箱收到压缩包，解压得到 `.xlsx` 文件

**支付宝**
1. 打开支付宝 →「我的」→「账单」
2. 右上角「···」→「开具交易流水证明」
3. 选择「用于个人对账」→ 选好时间范围 → 填邮箱
4. 邮箱收到压缩包，解压得到账单文件

### 第 4 步：分析

1. 双击 `账单分析器.exe`
2. 把导出的 `.xlsx` 文件**拖进虚线框**（拖不动就点「添加文件」）
3. 点「开始分析」

报告会自动在浏览器里打开。

> **可以一次拖多份**——多个月、多个渠道的文件一起拖进去，重复的交易会自动去掉。

**报告存在哪？** 默认在程序旁边的「报告」文件夹里。想换位置就点界面上的「更改…」，选过一次就会记住，下次打开还是那里；点「恢复默认」可以改回来。

## 常见问题

### 打开时提示「未知发布者」或「Windows 已保护你的电脑」

这是正常现象，**不是程序有问题**。原因有三个：

1. 程序没有数字签名。签名证书要按年付费购买，个人项目一般不会买。任何没有签名的 exe，Windows 都会提示「未知发布者」。
2. 打包工具（PyInstaller）生成的程序容易被杀软启发式规则误判——它把 Python 运行环境和依赖都塞进了可执行文件里，这种结构确实和某些恶意程序相似。

**怎么处理：**

- 弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
- 文件属性里有「此文件来自其他计算机」→ 右键 exe →「属性」→ 勾选「解除锁定」
- 想以后都不提示，可以把这个文件夹加进 Windows 安全中心的白名单（需要管理员权限）

### 拖进去没反应？

点「添加文件」按钮，功能完全一样——拖拽只是图个方便，不是唯一入口。

### 有些消费分类不对，怎么办？

两个办法：

- **改规则（一劳永逸）**：打开程序旁边的 `config\categories.json`（记事本就能编辑），
  在对应分类的 `keywords` 里加上商户名或关键词，保存后重新分析即可。
- **手工修正**：在 `config\corrections.json` 里写 `"商户名": "分类名"`，
  它的优先级最高，写进去就永久生效，规则和模型都覆盖不了你。

### 分类覆盖率不高？

正常。第一次跑的时候，程序可能不认识的商户会落到「其他」里。打开报告看「数据体检」那栏，
把不认识的商户按上面的办法补进 `categories.json`，跑几次之后覆盖率会明显提高——
这个过程本身就是在积累属于你自己的分类规则。

### 报告里的数字和我预想的不一样？

几个常见原因：

- **「不计收支」的转账不计入支出**——这类是资金搬运，不是消费
- **退款会从支出里扣掉**——你会在报告里看到「已扣除退款」的提示
- **跨渠道重复已去重**——同一笔在两边的记录只算一次

### 支持 Mac 和 Linux 吗？

目前只提供 Windows 版。

### 能分析信用卡账单、银行流水吗？

理论上可以，只要能导出成 `.xlsx` / `.csv` 并且有「时间 + 金额 + 对方」这几列。
如果格式差异较大读不出来，欢迎提 Issue 附上脱敏后的文件样例。

## 隐私说明

账单是高度敏感的个人数据，所以这件事说清楚：

- **完全离线**：分析全程在本机完成，程序不联网、不上传任何数据
- **不写系统**：不写注册表、不碰系统目录
- **产物都在明处**：所有结果文件都在程序自己的文件夹里，删掉文件夹就是彻底清除
- **规则是可读的**：全部分类逻辑就是一个纯文本 `categories.json`，用记事本就能看完
- **代码开源**：可以自己审计，也可以用 `python build_exe.py` 自己编译一份

唯一的联网行为是可选的「调用大模型辅助归类」，**默认关闭**，需要你自己配置 API Key 才会启用。
不配置也不影响使用——归类本身有四层，规则和人工修正这两层已经完全够用。

> 💡 把报告发给别人之前，记得先删掉「报告」文件夹——里面有你的真实消费记录。
